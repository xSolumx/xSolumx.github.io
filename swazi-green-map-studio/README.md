# Swazi Green Land Map Studio

Public deployment of the v2.7 mobile-first land-map viewer and editor.

Open the application at:

<https://xsolumx.github.io/swazi-green-map-studio/>

The application is a single self-contained HTML file with no runtime service,
account, analytics, inventory system or external dependency. Project drafts are
stored in the browser unless the user explicitly exports or downloads them.
